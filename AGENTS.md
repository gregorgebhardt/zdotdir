# Repository Guide

## Startup And Ownership

- This repository is the active `$ZDOTDIR`; `~/.zshenv` must symlink to this repo's `.zshenv` for Zsh to discover it.
- Startup flows through `.zshenv` -> `.zprofile` -> `.zshrc`. Interactive modules in `.zshrc.d/*.zsh` are sourced in lexical order after Antidote and `compinit`.
- Put PATH and environment defaults needed by non-interactive shells in `.zprofile`; put interactive tool hooks in `.zshrc.d/`.
- Files in `functions/` are added to `fpath` and autoloaded by filename. Completion functions use a leading underscore.

## Antidote

- Edit `.zsh_plugins.txt`, not `.zsh_plugins.zsh`; the latter is generated by `antidote load` and ignored by Git.
- Machine-specific plugins belong in the ignored `.zsh_plugins.local.txt`, which `.zshrc` loads after the shared plugin list.
- Plugin order is functional. Keep completion providers before `compinit`, deferred plugins only where safe, and autosuggestions/history-substring-search at the end.
- `.antidote/`, `.zcompcache/`, `.zcompdump*`, `*.zwc`, and `.zsh_plugins.zsh` are local/generated state; do not commit or hand-edit them.
- Local plugins must also be listed in `.zsh_plugins.txt`; `custom/plugins/opencode` is loaded this way.

## Verification

- There is no project test suite or CI. Syntax-check tracked Zsh sources after edits:
  `zsh -n .zshenv .zprofile .zshrc .aliases .zstyles .zshrc.d/*.zsh custom/plugins/*/*.zsh functions/*`
- For startup changes, run `zsh -lic exit`. This executes machine-local hooks and may access Homebrew, SafeChain, direnv, macOS Keychain, KeepassXC, or the network.

## Local And Sensitive State

- Preserve silent failure when optional credentials or local files are absent; never commit resolved secret values.
- Machine-specific overrides belong in ignored `*.local` or `*.local.zsh` files, but they are not sourced automatically unless an existing startup file explicitly sources them.
- `.zshrc` contains a managed Devin block; do not move or edit its boundary markers.
